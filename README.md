# Shorts Cutter Bot

Telegram-бот, который превращает длинное видео в вертикальные шортсы:
находит интересные моменты, режет их в формат 9:16, слегка уникализирует и добавляет субтитры в стиле TikTok.

## Режимы и монетизация

- **✂️ Свои тайминги — бесплатно**, но с дневным лимитом фрагментов (по умолчанию 5).
  Лимит обновляется каждый день — люди возвращаются в бота.
- **🤖 Авто-нарезка — Премиум.** Бот сам находит интересные моменты.
- **🎁 Рефералка:** у каждого своя ссылка (`/ref`). Когда приглашённый друг делает первую нарезку,
  пригласивший получает 3 дня Премиума. Дни складываются.

### Как вводить тайминги

1. **Окно разметки** (Telegram Mini App) — поля для начала и конца, кнопки «+15 с / +30 с / +1 мин».
   Для YouTube внутри окна есть плеер: включаешь видео и жмёшь «Начало» / «Конец».
2. **По шагам в чате** — бот спрашивает начало, потом конец (или длину кнопкой), потом «Ещё» или «Нарезать».
3. **Списком сразу** — вместе со ссылкой или в подписи к видео: `https://youtu.be/... 1:20-1:45, 5:10-5:40`.

Время можно писать цифрами без двоеточия: `1124` = `11:24`, `12030` = `1:20:30`.
До 10 фрагментов за раз, каждый до 3 минут.

Окно лежит в `docs/timecodes.html` и публикуется через GitHub Pages
(Settings → Pages → Branch: `main`, папка `/docs`). Адрес вписывается в `.env` как `WEBAPP_URL`.

### Сервисы и заглушки

Бот запускается и работает без единого ключа: вместо неподключённых сервисов стоят заглушки.
Что подключено, админ видит в `/stats`, а при установке — в `python check.py`.

| Сервис | Что включить в `.env` | Пока не подключён |
|---|---|---|
| Распознавание речи (Groq) | `GROQ_API_KEY` | нарезка без субтитров, авто-нарезка «скоро» |
| ИИ выбор моментов | `LLM_API_KEY` (или тот же ключ Groq) | моменты выбираются по плотности речи |
| Оплата Премиума | `PAYMENT_PROVIDER` + код в `payments.py` | кнопка «Купить» показывает тарифы, считает интерес и пишет «скоро» |
| Окно разметки | `WEBAPP_URL` | тайминги вводятся в чате |
| Local Bot API | `BOT_API_URL` | файлы до 20 МБ |

### Команды

| Команда | Что делает |
|---|---|
| `/limit` | остаток на сегодня |
| `/ref` | реферальная ссылка и статистика |
| `/premium` | статус и как получить Премиум |
| `/buy` | тарифы Премиума (пока заглушка) |
| `/settings` | уникализация, формат, субтитры |
| `/cancel` | отменить разметку |
| `/give <id> <дней>` | (админ) выдать Премиум |
| `/stats` | (админ) статистика бота |

## Как это работает

1. **Распознавание речи** — Groq Whisper (бесплатный лимит), таймкод для каждого слова.
2. **Выбор моментов** — нейросеть читает транскрипт и выбирает фрагменты с хуком.
3. **Монтаж** — FFmpeg: вертикальный формат (размытый фон или обрезка), уникализация, субтитры с подсветкой слова.

```
shorts/            ядро (работает без Telegram)
  transcribe.py    распознавание речи
  highlights.py    выбор моментов
  subtitles.py     субтитры
  render.py        монтаж
  timecodes.py     разбор таймингов для ручного режима
  pipeline.py      всё вместе (авто и ручной режим)
clip.py            запуск из командной строки
bot.py             Telegram-бот
storage.py         база данных (SQLite): премиум, лимиты, рефералы
payments.py        оплата Премиума (пока заглушка)
docs/timecodes.html  окно разметки таймингов (Telegram Mini App)
check.py           проверка настройки
tests/             тесты ядра (запускаются на GitHub при каждом изменении)
```

## Установка на Windows

1. **Python 3.11+** — скачай с python.org. При установке поставь галочку **Add Python to PATH**.
2. **FFmpeg** — в PowerShell: `winget install Gyan.FFmpeg`, потом перезапусти PowerShell.
3. **Git** — `winget install Git.Git`.
4. Скачай проект и установи зависимости:
   ```powershell
   git clone https://github.com/anons23/shorts-cutter-bot..git
   cd shorts-cutter-bot.
   python -m venv .venv
   .venv\Scripts\activate
   pip install -r requirements.txt
   ```
5. Скопируй `.env.example` в `.env` и впиши ключи: `copy .env.example .env`, затем `notepad .env`.

> Groq из России работает только через VPN — включи его перед запуском.

6. Проверь, что всё настроено: `python check.py`. Скрипт покажет, чего не хватает и как это исправить.

## Проверка

```powershell
# 1) Тест монтажа без интернета и ключей (фейковые субтитры):
python clip.py C:\путь\к\видео.mp4 --fake --no-llm --clips 2

# 2) Полный цикл с распознаванием речи и нейросетью:
python clip.py C:\путь\к\видео.mp4

# 3) Повторный монтаж без новых запросов к Groq:
python clip.py C:\путь\к\видео.mp4 --transcript output\transcript.json
```

```powershell
# 4) Свои тайминги вместо авто-поиска:
python clip.py C:\путь\к\видео.mp4 --times "0:45-1:20, 3:10-3:55"
```

Готовые шортсы появятся в папке `output`. Опции: `--unique none|light|strong`, `--layout blur|crop`, `--res 720|1080`, `--clips N`, `--no-subs`.

## Запуск бота

```powershell
python bot.py
```

В боте: пришли видео файлом (до 20 МБ без своего Bot API сервера) или ссылку на YouTube,
затем выбери «Авто» или «Свои тайминги». Можно сразу написать тайминги вместе со ссылкой
или в подписи к видео: `https://youtu.be/... 1:20-1:45, 5:10-5:40`.
`/settings` — настройки, `/limit` — остаток на сегодня.

Для файлов до 2 ГБ впиши в `.env` адрес своего Local Bot API Server: `BOT_API_URL=http://localhost:8081`.
