# Shorts Cutter Bot — контекст проекта

Этот файл — передача контекста для новых сессий Claude. Прочитай его целиком, прежде чем что-то менять.

## О владельце и как с ним работать

- Владелец — **без опыта программирования**. Объясняй простым языком, по шагам, давай команды целиком, которые можно скопировать.
- Общение **на русском**.
- Работает на **Windows** (PowerShell, VS Code). Есть VPN. Есть **Local Bot API Server** на ПК (детали подключения ещё не присылал: Docker или нет, порт, папка файлов).
- **Ключи и токены никогда не просить прислать в чат** — они только в `.env` у владельца.
- Сейчас этап — **собрать концепцию**: внешние сервисы (ИИ, оплата) стоят заглушками, подключаются позже. Ничего не должно ломаться без ключей.
- Владелец предпочитает щедрые условия для первых пользователей, а не навязчивые ограничения: **обязательный водяной знак отклонён** (только по желанию за бонус), **ничего не даём «навсегда»** — только временный Премиум.

## Идея продукта

Telegram-бот: из длинного видео делает вертикальные шортсы (9:16) с субтитрами в стиле TikTok и лёгкой уникализацией.
Целевая аудитория — русскоязычные блогеры и SMM; крупные аналоги (OpusClip, Vizard, Klap) зарубежные и неудобны для РФ.

## Монетизация и рост (решения владельца)

- **✂️ Свои тайминги — бесплатно**, лимит **5 фрагментов в день** (обновляется в полночь по Омску) — чтобы люди заходили каждый день.
- **🤖 Авто-нарезка (ИИ ищет моменты) — только Премиум.**
- **Рефералка:** приглашённый получает +5 фрагментов на первые сутки; пригласивший получает 3 дня Премиума, когда друг сделал первую нарезку. Дни складываются.
- **Первые 300 пользователей** получают 7 дней Премиума и красивое сообщение «Ты — №N из первых 300».
- **Водяной знак только по желанию** — за него +3 фрагмента в день.
- **Напоминание «лимит обновился»** — только тем, кто сам включил (10:00 по Омску).
- **Оплата — заглушка**: кнопка «Купить» показывает тарифы (7 дн. 149 ₽, 30 дн. 399 ₽) и считает интерес в `/stats`. Вероятный способ — звёзды Telegram (решение не принято).
- Все числа настраиваются в `.env` (см. `.env.example`).

## Что уже сделано

- **Ядро `shorts/`** (работает без Telegram, запуск `python clip.py video.mp4`):
  распознавание речи Groq Whisper (`transcribe.py`), выбор моментов LLM с запасным простым способом (`highlights.py`),
  субтитры ASS — 5 стилей, позиция, хук, водяной знак (`subtitles.py`), монтаж FFmpeg — размытый фон или обрезка
  по лицу, 3 уровня уникализации (`render.py`, `face.py`), раскадровка (`storyboard.py`), разбор таймингов (`timecodes.py`).
- **Бот `bot.py`** (aiogram 3): приём файла или ссылки YouTube → выбор режима → тайминги тремя способами
  (окно Mini App, пошагово в чате с кнопками +15/+30/+45/+60 с, списком); с YouTube качаются только нужные куски;
  очередь по одной задаче; лимит списывается при постановке в очередь и возвращается при ошибке.
- **Окно разметки** `docs/timecodes.html` — Telegram Mini App (статическая страница, отдаёт данные через `sendData`,
  открывается только кнопкой reply-клавиатуры). Для YouTube внутри есть плеер с кнопками «Начало/Конец».
  Хостинг — **GitHub Pages** (свой домен не нужен). **Владелец ещё не включил Pages**:
  Settings → Pages → ветка `main`, папка `/docs`; затем адрес в `.env` как `WEBAPP_URL`.
- **База `storage.py`** (SQLite, `bot.db`): пользователи, премиум, лимиты, бонусы, рефералы, напоминания, события, журнал ошибок.
  Новые колонки добавляются в старую базу автоматически.
- **Заглушки** (`/stats` показывает, что подключено): без `GROQ_API_KEY` — нарезка без субтитров, авто «скоро»;
  без `LLM_API_KEY` — простой выбор моментов и без хука; без `PAYMENT_PROVIDER` — оплата «скоро»;
  без `WEBAPP_URL` — тайминги только в чате; без `BOT_API_URL` — файлы до 20 МБ.
- **Админ** (`ADMIN_IDS`): `/give <id> <дней>`, `/stats`, `/errors`, `/broadcast` (ответом на сообщение, с подтверждением).
- **`check.py`** — проверка установки и ключей. **Тесты** `tests/` + GitHub Actions (`.github/workflows/test.yml`).

## Что НЕ проверено вживую

Бот ни разу не запускался в настоящем Telegram. Не проверены: Groq и LLM с реальными ключами,
скачивание кусков с YouTube через yt-dlp, Local Bot API, окно разметки внутри Telegram и плеер YouTube в нём,
отправка напоминаний по времени. Всё это проверено только тестами с заглушками.

## Следующие шаги

1. Запустить на ПК владельца (Windows): Python, FFmpeg (`winget install Gyan.FFmpeg`), `pip install -r requirements.txt`,
   `.env` по образцу, `python check.py`, затем `python bot.py`. Подключить его Local Bot API.
2. Включить GitHub Pages и вписать `WEBAPP_URL`.
3. Переименовать репозиторий без точки на конце (сейчас `shorts-cutter-bot.` — на Windows такие папки работают плохо).
4. Позже: ключи ИИ (Groq бесплатно на старте; из РФ нужен VPN или зарубежный сервер),
   оплата, деплой на сервер владельца с автозапуском.

## Инфраструктура владельца

- Сервер: зарубежный VPS (Oracle free 1 ядро/1 ГБ или вариант за ~€2: 1 ядро/4 ГБ/10 ГБ диска). Диск маленький —
  временные файлы удаляются сразу после обработки, рендер по умолчанию 720p.
- Есть второй проект — бот **Media Hunter** (`anons23/media_hunter_bot`), там свой домен для Mini App.

## Правила для кода

- Комментарии и тексты бота — на русском.
- Любой внешний сервис — через проверку ключа и понятную заглушку, без падений.
- Новые функции — с тестами; `python -m unittest discover tests` должен проходить.
- Коммиты в ветку, проверка GitHub Actions, потом fast-forward в `main`.
